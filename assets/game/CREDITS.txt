Sound effects (assets/audio/)
  Kenney (kenney.nl) — "Impact Sounds", "Interface Sounds", "Digital Audio".
  Licensed CC0 1.0 Universal (public domain).
  turret_shot / turret_shot_b / explosion_big / battery_launch / planet_hit /
  card_reveal are synthesised for this project (layered filtered noise +
  chirp/sweep tones + sub-bass via ffmpeg — see tools/gen_sfx.sh) — original
  content, no third-party samples. card_reveal plays once when the upgrade
  draft popup opens (a rising shimmer, distinct from card_pick's confirm
  chime below). The laser shots (turret_shot / turret_shot_b) replaced
  Kenney's "Sci-Fi Sounds" pack at v0.24.0 for a punchier, more textured zap.
  mission_won / mission_lost / card_pick / ability_cast / explosion /
  explosion_b / shield / ui_click / missile_launch / sentinel_shot were
  replaced with real samples pulled out of Planet Defense: Space TD's own
  FMOD sound bank (CyberJoy Games, com.cyberjoy.prjw5n2 — assets/fmod/
  SFX.bank, extracted via the `fsb5` library; see tools/extract_pdtd_audio.py
  for the full pipeline and which of the bank's 79 samples were and weren't
  safe to reuse). explosion / explosion_b / missile_launch were additionally
  trimmed down from their raw multi-second library-clip length to a punchy
  one-shot (explosion/explosion_b fire on every kill; missile_launch backs
  the hero's Missile Barrage). Per the user's explicit 2026-09-15 OK to use
  PDTD's assets in this personal, never-published build (CLAUDE.md §4).

Shield surface texture (assets/game/shield/hex_pattern.png)
  Extracted from Planet Defense: Space TD's own force-shield material
  (CyberJoy Games, com.cyberjoy.prjw5n2) via UnityPy, per the user's explicit
  2026-09-15 OK to use PDTD's assets in this personal, never-published build
  (see CLAUDE.md §4). Re-processed (luminance -> alpha) so it composites as a
  translucent hex-line overlay instead of an opaque black square.

Hero/battery missile sprite (assets/game/missile.png)
  Extracted from Planet Defense: Space TD's own missile weapon VFX (CyberJoy
  Games, com.cyberjoy.prjw5n2 — assets/Res/gameobjects/weapon/missile/
  texture/supermissile01.png.ab) via UnityPy, same permission as above.
  Re-processed (luminance -> alpha, rotated so the nose points "up" to match
  this renderer's sprite convention, downscaled).

Enemy + boss sprites (assets/game/enemies/*.png)
  All 11 replaced at v0.25.2 with real Planet Defense: Space TD art (CyberJoy
  Games, com.cyberjoy.prjw5n2), extracted via UnityPy from each prefab's
  `textures/battleship/**/*.png.ab` dependency and re-processed (crop to
  content, rotate so the nose points "up" per this renderer's sprite
  convention — only `siege_crawler` needed a 180° flip, downscale). An
  earlier session wrongly assumed PDTD's enemies/bosses were 3D meshes that
  couldn't be flattened without stretching/seaming — a direct inspection of
  the Unity data (SpriteRenderer-only components, no Mesh/MeshRenderer/
  SkinnedMeshRenderer anywhere) showed they're flat pre-rendered sprites like
  the missile art above, so the swap was the same scope of work. Source
  prefab per enemy: skiff <- union/union_drone_small, hauler <-
  union/union_transport_big, interceptor <- wind/wind_hunter_middle,
  aegis_cruiser <- union/union_escort_big, bombard <- union/union_laseratk_middle,
  carrier <- bug/bug_hive_big, phase_runner <- watch/watch_timeecho_small,
  leech <- bug/bug_leech_small, warden <- wind/wind_repairunit_big,
  siege_crawler <- wind/wind_siege_big, boss_threshing_gate <-
  bug/bug_wallmaker_boss. `SimRenderer.EnemyTint` was reset to near-white for
  all of these — the old tint values existed to give the plain Kenney
  placeholders visual variety, but multiplying a strong tint onto PDTD's own
  baked-in color identity (gold/red/blue-grey/black chitin, ...) would wash
  it out or recolor it oddly.
  Turret/sentinel visuals were investigated the same pass and left as Kenney
  art: PDTD's own build has exactly one player turret (`prefab/gun/`, two
  variants), so there's no roster of 8 distinct PDTD turret designs to draw
  from the way there was for the 11-enemy roster — see docs/ROADMAP.md.

Upgrade-card art (assets/game/cards/*.jpg)
  Supplied by the project owner (AI-generated key art for the ship-weapon and
  planet orbital-weapon upgrade cards, and the Planet Shield). Personal build.
  The 4 new orbital-weapon cards added when the sentinel roster was extended
  to match PDTD's full 11-weapon list (waterdrop, space_bomb, force_field,
  sweep_laser — see docs/ROADMAP.md) are an exception: no AI art was supplied
  for these, so they're procedurally generated instead (`tools/gen_cards.py`
  — radial nebula gradient + starfield + a drawn glyph, in the weapon's own
  accent color, matching the card-frame language used elsewhere). Original
  content, no third-party source.
