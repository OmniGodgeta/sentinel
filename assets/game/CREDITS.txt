Sound effects (assets/audio/)
  Kenney (kenney.nl) — "Impact Sounds", "Interface Sounds", "Digital Audio".
  Licensed CC0 1.0 Universal (public domain).
  turret_shot / turret_shot_b / explosion_big / battery_launch / planet_hit /
  card_reveal are synthesised for this project (layered filtered noise +
  chirp/sweep tones + sub-bass via ffmpeg — see tools/gen_sfx.sh) — original
  content, no third-party samples. card_reveal plays once when the upgrade
  draft popup opens (a rising shimmer, distinct from card_pick's confirm
  chime below). The laser shots (turret_shot / turret_shot_b) replaced
  Kenney's "Sci-Fi Sounds" pack at v0.24.0 for a punchier, more textured zap.
  mission_won / mission_lost / card_pick / ability_cast / explosion /
  explosion_b / shield / ui_click / missile_launch / sentinel_shot /
  orbital_laser_fire / space_bomb_fire / waterdrop_fire / ball_lightning_fire /
  radiation_line_fire (shared by radiation_zone too) / orbital_lightning_fire /
  beam_fire were replaced with real samples pulled out of Planet Defense: Space TD's own
  FMOD sound bank (CyberJoy Games, com.cyberjoy.prjw5n2 — assets/fmod/
  SFX.bank, extracted via the `fsb5` library; see tools/extract_pdtd_audio.py
  for the full pipeline and which of the bank's 79 samples were and weren't
  safe to reuse). explosion / explosion_b / missile_launch were additionally
  trimmed down from their raw multi-second library-clip length to a punchy
  one-shot (explosion/explosion_b fire on every kill; missile_launch backs
  the hero's Missile Barrage). Per the user's explicit 2026-09-15 OK to use
  PDTD's assets in this personal, never-published build (CLAUDE.md §4).

Sentinel models + weapon VFX (assets/game/pdtd/**)
  Real Planet Defense: Space TD art (CyberJoy Games, com.cyberjoy.prjw5n2),
  extracted with UnityPy from UnityDataAssetPack.apk, per the user's explicit
  2026-09-15 OK to use PDTD assets in this personal, never-published build
  (CLAUDE.md §4). Two sets:
    icons/<kind>.png  — the 11 sentinel platform renders from
      assets/Res/skins/sentinel/000NN_<weapon>/ui/*_mainicon.png, downscaled to
      256px. Used both as the in-world orbiting platform sprite and as the icon
      on the HUD's bottom weapon cards.
    vfx/*.png — the weapon effect textures: laserbeam01/03/05 (beams),
      weapon/aqua.png (Waterdrop bolt), weapon/radiationpoint.png (Radiation
      Link relay), spacebomb energyball/ring/shockwave/bomb_flare,
      orb circle/point/shield (Ball Lightning core, Force Field dome),
      lightningarches lightning_big2/lightning_new (chain arcs), plus
      glow/flare/explosion/missiletrail.
  bomb_flare, explosion, missile_trail, orb_circle, orb_shield and ring came
  out of Unity with a black backing instead of transparency, so they were
  re-processed luminance->alpha (same fix the missile sprite needed at
  v0.25.1); shockwave's alpha peaked at 67/255 and was normalised.

Enemy + boss sprites (assets/game/enemies/*.png)
  All 11 replaced at v0.25.2 with real Planet Defense: Space TD art (CyberJoy
  Games, com.cyberjoy.prjw5n2), extracted via UnityPy from each prefab's
  `textures/battleship/**/*.png.ab` dependency and re-processed (crop to
  content, rotate so the nose points "up" per this renderer's sprite
  convention — only `siege_crawler` needed a 180° flip, downscale). An
  earlier session wrongly assumed PDTD's enemies/bosses were 3D meshes that
  couldn't be flattened without stretching/seaming — a direct inspection of
  the Unity data (SpriteRenderer-only components, no Mesh/MeshRenderer/
  SkinnedMeshRenderer anywhere) showed they're flat pre-rendered sprites like
  the missile art above, so the swap was the same scope of work. Source
  prefab per enemy: skiff <- union/union_drone_small, hauler <-
  union/union_transport_big, interceptor <- wind/wind_hunter_middle,
  aegis_cruiser <- union/union_escort_big, bombard <- union/union_laseratk_middle,
  carrier <- bug/bug_hive_big, phase_runner <- watch/watch_timeecho_small,
  leech <- bug/bug_leech_small, warden <- wind/wind_repairunit_big,
  siege_crawler <- wind/wind_siege_big, boss_threshing_gate <-
  bug/bug_wallmaker_boss. `SimRenderer.EnemyTint` was reset to near-white for
  all of these — the old tint values existed to give the plain Kenney
  placeholders visual variety, but multiplying a strong tint onto PDTD's own
  baked-in color identity (gold/red/blue-grey/black chitin, ...) would wash
  it out or recolor it oddly.
  Turret/sentinel visuals were investigated the same pass and left as Kenney
  art: PDTD's own build has exactly one player turret (`prefab/gun/`, two
  variants), so there's no roster of 8 distinct PDTD turret designs to draw
  from the way there was for the 11-enemy roster — see docs/ROADMAP.md.

Upgrade-card art (assets/game/cards/*.jpg)
  Supplied by the project owner (AI-generated key art for the ship-weapon and
  planet orbital-weapon upgrade cards, and the Planet Shield). Personal build.
  2 of the orbital-weapon cards are an exception: no art was supplied for
  these, so they're procedurally generated instead (waterdrop, force_field —
  added to match PDTD's weapon list, see docs/ROADMAP.md). Generated via `tools/gen_cards.py`
  — radial nebula gradient + starfield + a drawn glyph, in the weapon's own
  accent color, matching the card-frame language used elsewhere). Original
  content, no third-party source.

Planet Defense: Space TD — UI sprites (added 2026-09-17, v0.30.0)
  Extracted by tools/extract_pdtd_sprites.py from the same XAPK the audio and
  enemy art came from. Copyrighted, used under CLAUDE.md §4's standing user
  exception (sideload-only personal build, never published). All of this would
  need to come out before any public release.

  pdtd/cardui/*        — PDTD's skill-card chrome: slot_background (back plate),
    slot_front_{normal,super,relic,ultimate} (the per-rarity front plates, each
    with a transparent art window), the matching outlines, slot_light_* (glow),
    slot_selected, and icon_star_normal_1..5 (the hex star pips). This is what
    the in-run draft cards are now built from.
  pdtd/skillicon/*     — the seven weapon glyphs (missile, droplet, laser,
    focusedbeam, radiationline, railgun, dimensionalgrenade) plus the
    damage-type and attribute icons. NOTE the weapon seven are full-bleed card
    illustrations and are deliberately NOT run through the luminance-as-alpha
    fix; the attribute icons are true cut-out glyphs with real alpha. Neither
    group wants it — see the extractor's docstring.
  pdtd/techpoint/*     — the twelve per-weapon tech-point emblems. Used as the
    watermark behind Research and Codex rows and as card art for the sentinels
    PDTD has no flat glyph for.
  pdtd/rarity/*        — itembg_{common,fine,rare,epic,legendary,supreme,
    ultimate} quality plates, item outline/star/slot. Behind item drops.
  pdtd/loot/*          — silver/gold key, chest, coin, exp, research core,
    techpoint, shield capacitor/integrator, rebuild core, crystal, medal.
  enemies/miniboss_siege_warden.png — PDTD's wind_cruiser_boss hull, the
    mini-boss added this version. Same flat-sprite situation as the v0.25.2
    enemy art.

  cards/waterdrop.jpg and cards/force_field.jpg were rebuilt by
  tools/gen_pdtd_cards.py out of the card chrome above plus PDTD's own droplet
  art / Force Field platform render. They were the last two procedural-gradient
  placeholders; they are no longer original work and would need replacing along
  with everything else here before any public release.

  Audio re-picked this version (same bank, same exception): missile_launch <-
  sample 43, battery_launch <- 58, explosion_big <- 44.

v0.31.0 additions (same PDTD source, same CLAUDE.md §4 exception):
  pdtd/icons/*  and  pdtd/tiles/*  — the canonical per-sentinel art, pulled by
    tools/extract_pdtd_sentinels.py from PDTD's own skins/sentinel/000NN_<weapon>
    directories. `icons/` is each craft's `_mainicon` on transparent alpha (the
    orbiting model); `tiles/` is that craft composited over its own `_bg` plate,
    which is how PDTD builds the card and HUD tile. This replaces the previous
    ad-hoc icons/ set: sourcing all eleven from PDTD's numbered directories makes
    the weapon->art mapping correct by construction rather than by eye, and
    supplies the four (radiation zone, force field, chain lightning, ball
    lightning) that had no flat sprite anywhere in the bundle.
  pdtd/chest/*  — box_{sentinel,planet,mothership,shield}, the grey/purple chest
    plates from the slot UI, and the two shop box backgrounds. Armory.
  pdtd/chip/*   — chipicon_* rarity plates, the empty/outline/quality slot
    plates, and the 27 chip_affix glyphs. Chip screen.
  pdtd/module/* — the six equipment-family icons and their art (weapon, shield,
    engine, reactor, radar, quantacore), designslot, and the tech slot frames.
  pdtd/alloy/*  — ultimate_alloy_1000N, one uniform cartridge glyph per sentinel
    (the skillicon set only covers seven of the eleven).

  data/skillcards.json is generated by tools/gen_skillcards.py from PDTD's
  shipping skill_upgrade_data: 187 upgrade cards whose titles and descriptions
  are PDTD's verbatim. That is copied text, not original writing, and would need
  rewriting before any public release along with everything else here.
