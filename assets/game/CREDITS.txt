Sound effects (assets/audio/)
  Kenney (kenney.nl) — "Impact Sounds", "Interface Sounds", "Digital Audio".
  Licensed CC0 1.0 Universal (public domain).
  turret_shot / turret_shot_b / explosion_big / battery_launch / planet_hit
  are synthesised for this project (layered filtered noise + chirp/sweep
  tones + sub-bass via ffmpeg — see tools/gen_sfx.sh) — original content, no
  third-party samples. The laser shots (turret_shot / turret_shot_b) replaced
  Kenney's "Sci-Fi Sounds" pack at v0.24.0 for a punchier, more textured zap.
  mission_won / mission_lost / card_pick / ability_cast / explosion /
  explosion_b / shield / ui_click / missile_launch / sentinel_shot were
  replaced with real samples pulled out of Planet Defense: Space TD's own
  FMOD sound bank (CyberJoy Games, com.cyberjoy.prjw5n2 — assets/fmod/
  SFX.bank, extracted via the `fsb5` library; see tools/extract_pdtd_audio.py
  for the full pipeline and which of the bank's 79 samples were and weren't
  safe to reuse). explosion / explosion_b / missile_launch were additionally
  trimmed down from their raw multi-second library-clip length to a punchy
  one-shot (explosion/explosion_b fire on every kill; missile_launch backs
  the hero's Missile Barrage). Per the user's explicit 2026-09-15 OK to use
  PDTD's assets in this personal, never-published build (CLAUDE.md §4).

Shield surface texture (assets/game/shield/hex_pattern.png)
  Extracted from Planet Defense: Space TD's own force-shield material
  (CyberJoy Games, com.cyberjoy.prjw5n2) via UnityPy, per the user's explicit
  2026-09-15 OK to use PDTD's assets in this personal, never-published build
  (see CLAUDE.md §4). Re-processed (luminance -> alpha) so it composites as a
  translucent hex-line overlay instead of an opaque black square.

Hero/battery missile sprite (assets/game/missile.png)
  Extracted from Planet Defense: Space TD's own missile weapon VFX (CyberJoy
  Games, com.cyberjoy.prjw5n2 — assets/Res/gameobjects/weapon/missile/
  texture/supermissile01.png.ab) via UnityPy, same permission as above.
  Re-processed (luminance -> alpha, rotated so the nose points "up" to match
  this renderer's sprite convention, downscaled). Enemy/boss/sentinel *visual*
  replacement was investigated and intentionally NOT done this pass — see
  docs/ROADMAP.md §6a for why (PDTD's characters are 3D meshes with UV-mapped
  materials; this renderer draws flat 2D sprites, so a direct texture swap
  would look stretched/seamed, unlike this VFX billboard which works fine
  flat in both engines).
